First release.

## What's in it

`orv` reads OpenReview through the public API at `api2.openreview.net`.
No API key required. Public ML conference data only.

### Commands

| command | what it does |
|---|---|
| `orv search <query>` | Full-text search across all notes |
| `orv venue <venue-id>` | List papers submitted to a venue |
| `orv paper <id>` | Show a single paper by OpenReview note ID |
| `orv top` | List well-known ML conference venues |

All commands support `-o table|json|jsonl|csv|tsv|url|raw`, `--fields`,
`--template`, `-n/--limit`.

## Install

```bash
go install github.com/tamnd/openreview-cli/cmd/orv@v0.1.0
```

Or download a prebuilt binary from the [releases page](https://github.com/tamnd/openreview-cli/releases/tag/v0.1.0).
